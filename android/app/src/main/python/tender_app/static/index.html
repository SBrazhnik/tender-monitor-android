Как работают признаки

Вендор или продукт ищется целым словом: «Astra» не сработает на «Астрахань».

Ключевое слово ищется по началу слова: «виртуализ» найдёт «виртуализации». Короткие заглавные (SIEM, АРМ, ПК) ищутся целым словом с учётом регистра.

ОКПД2 задаётся кодом или его началом: «26.20» охватит 26.20.15.000.

Исключения отменяют срабатывание: «Opel Astra», «автоматических выключателей».

После правок нажмите «Пересчитать найденные закупки». Для сложных случаев есть регулярные выражения с префиксом re:.
