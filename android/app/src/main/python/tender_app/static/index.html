Как работают признаки

Вендор / продукт — ищется целым словом: «Astra» не сработает на «Астрахань». Вендор объединяет свои продукты (Astra → Astra Linux, ALD Pro, Brest).

Ключевое слово — по началу слова: «виртуализ» найдёт «виртуализации». Короткие ЗАГЛАВНЫЕ (SIEM, АРМ, ПК) — целым словом с учётом регистра.

ОКПД2 — код или начало кода: «26.20» охватит 26.20.15.000.

Исключения — фразы, которые не должны давать срабатывание по направлению («Opel Astra», «автоматических выключателей»).

Раздел можно выключить целиком — его признаки перестанут учитываться. После правок нажмите «Пересчитать найденные закупки».

Для сложных случаев — регулярное выражение с префиксом re:.
