# Мониторинг закупок ИТ · ИБ · АСУТП — Android

Приложение работает полностью на телефоне: поиск по ЕИС, Сбербанк-АСТ, B2B-Center и порталу
Росатома, разбор документации, планы закупок, уведомления о новых закупках.

* Интерфейс — тот же, что у версии для компьютера (`android/app/src/main/python/tender_app`).
* Python внутри APK — Chaquopy; оболочка — Kotlin (`android/app/src/main/java/ru/tendermonitor`).
* Фоновый поиск — WorkManager по расписанию из вкладки «Расписание»; на время поиска —
  уведомление «Идёт поиск закупок» (служба переднего плана, чтобы Android его не прервал).

## Сборка
APK собирается автоматически GitHub Actions при каждом изменении ветки `main`
(вкладка Actions → «Сборка APK»). Готовый файл — в разделе Releases.

Ключ подписи `android/app/release.jks` хранится в репозитории (он приватный), чтобы каждая новая
сборка ставилась поверх старой без удаления данных.
